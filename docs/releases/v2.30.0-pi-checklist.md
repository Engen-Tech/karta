# Karta 2.30.0 Pi package release checklist

This checklist covers Karta's first Pi package release. It does not authorize publication. The package stays `private: true` and `UNLICENSED` until the owner explicitly approves licensing, ownership, version, tag, and registry publication.

Current verdict: **technically ready on the supported platforms, but not releasable**. Owner approval for licensing, package ownership, publication, and the release tag is still open.

## Package identity

- [x] Package name is `@engen-tech/karta`.
- [x] Version is `2.30.0`.
- [x] License is `UNLICENSED`.
- [x] `private: true` remains set.
- [x] Pi is a peer dependency at `*`, as Pi packages require.
- [x] The development dependency is pinned to the tested Pi release, 0.84.2.
- [x] One explicit extension ships from `extensions/pi/index.ts`; skills remain trust-discovered rather than statically listed.

## Native compatibility

The detailed evidence is in [the Pi support matrix](../how-to/pi.md#current-support-matrix).

- [x] macOS 26.5.2 arm64: full Pi suite, repository validators, package lifecycle, SHA-1/SHA-256 plumbing, and production audit.
- [x] Linux x86_64: full Pi suite, repository validators, package lifecycle, SHA-1/SHA-256 plumbing, mode smoke, and production audit on native Debian 13.
- [x] Windows x86_64 is outside the 2.30.0 support scope; native Windows support is deferred to a later release.
- [x] Pi TUI smoke on macOS and Linux.
- [x] Pi print-mode smoke on macOS and Linux.
- [x] Pi JSON-mode smoke on macOS and Linux.
- [x] Pi RPC package discovery and fixed-action smoke on macOS and Linux.

A container or compatibility layer may help diagnose a failure. It does not satisfy a native row.

## Provider compatibility

- [x] Stored API key completes preflight, acceptance tools, safety tools, and strict verdict parsing.
- [x] Environment API key completes the same roundtrip.
- [x] Runtime key completes the same roundtrip.
- [x] Declarative custom provider copies its static header and completes the same roundtrip.
- [x] Stored OAuth completes a live `openai-codex/gpt-5.6-sol` preflight, evidence-tool call, and strict verdict.
- [x] Dynamic native providers fail before child creation.
- [x] Provider configurations with executable `streamSimple`, `refreshModels`, or OAuth callbacks fail before child creation.
- [x] Shutdown aborts an active isolated provider stream.

The live OAuth row is opt-in so ordinary test runs do not require credentials or network access.

Mac, local terminal in the Karta checkout:

```sh
KARTA_LIVE_OAUTH=1 node --experimental-strip-types --test tests/pi/gate-oauth-live.test.ts
```
